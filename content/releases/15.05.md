## OpenWrt 15.05.1 — First Service Release · March 2016

### Highlights In OpenWrt 15.05.1

Some selected highlights of the service release are:

- Linux kernel updated to version 3.18.23
- Security fixes:
  - kernel: fix keyring reference leak (CVE-2016-0728)
  - openssl updated to 1.0.2f
  - hostapd security fixes
  - samba36 (CVE patches from 2015-12-16)
- Update of netifd, procd, uci, rpcd, ubox & uhttpd
- Driver updates
  - ledtrig-netdev: fix possible deadlock
  - bcm47xxpart: fix bcm53xx booting on NAND with badblocks
  - brcmfmac: fix getting/setting TX power, add stations dumping and support beamforming
  - 8139c: backport v4.3 fixes
  - backport spi layer fixes from v4.2+
  - solos-pci: increase headroom on RX
  - xrx200-net: fix port mirroring issues
  - update mac80211 (adding mt76)
- Support for new devices:
  - Linksys WRT1900ACS (mvebu)
  - D-LINK DIR-615 rev. Ix (ar71xx)
  - LinkIt Smart7688 (ramips)
  - Gainstrong MiniBox v1.0 (ar71xx)
  - ZBT WG2626 (ramips)
  - TP-LINK TL-WR841N/ND v10 (ar71xx)
  - TL-WR741ND v5 (ar71xx)
  - WR740N v5.0 (ar71xx)
  - TP-LINK TL-WR941ND v6 international version (ar71xx)
- Improved support for existing devices:
  - Netgear R8000: USB power and CPU speed
  - RapsberryPi: Add sysupgrade support
- Kernel fixes
  - ramoverlay
  - multicast-to-unicast
  - ip6_fragment related skb_leak
- Package fixes
  - igmpproxy: spurious restart issues

Have fun!

The OpenWrt developer team

## OpenWrt 15.05 "Chaos Calmer"

The OpenWrt developers are proud to announce the final release of OpenWrt Chaos Calmer.

\*\* Highlights since Barrier Breaker \*\*

- Linux kernel updated to version 3.18
- Improved Security Features
  1.  Rewritten package signing architecture based on ed25519
  2.  Added support for jails
  3.  Added support for hardened builds
- Improved Networking Support
  1.  Added or improved support for lots of 3G/4G modems (MBIM, QMI, NCM, …)
  2.  Added support for 464XLAT (CLAT) \[RFC 6877 + RFC 7050\]
  3.  Netfilter performance enhancements (conntrack route cache)
  4.  Improved support for self-managing networks \[draft-ietf-homenet-hncp\]
  5.  Better multi-core support for the network stack
  6.  Improved support for MAP-E, MAP-T and LW4over6 IPv4 transitioning technologies\
      \[draft-ietf-softwire-map, -map-t, -map-dhcp, -lw4over6\]
  7.  Improved network auto-setup capable of detecting and bootstrapping IPv4-only, 6rd, Dual-Stack, IPv6-only, DS-Lite, LW4over6, MAP-E, MAP-T, 464XLAT and combinations without explicit configuration \[based on RFC 7084\]
  8.  Added support for Smart Queue Management (SQM) QoS, AQM and Traffic Shaping
  9.  Improved support for DNSSEC
- Platform and Driver Support
  1.  Added support for feeds of externally maintained targets
  2.  New mt7621 subtarget for Mediatek 11ac SoC
  3.  New mt76 mac80211 based wifi driver for MTK 11ac cores.
  4.  New mwlwifi mac80211 based wifi driver for the Marvell 88W8864
  5.  New bcm53xx target for Broadcom ARM BCM47xx/53xx devices
  6.  New mxs target for Freescale i.MX23/28 family and various boards
  7.  New sunxi target for AllWinner A10/A13/A20 family and various boards
  8.  brcm2708: support for Raspberry Pi 2
  9.  brcm63xx: support for BCM6318 and BCM63268 family
  10. brcm63xx: improved fallback sprom support with bcma support

\*\* Improvements since RC 3 \*\*
