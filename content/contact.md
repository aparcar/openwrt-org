One of OpenWrt's goals is that all project-related communication is done via channels that are archived and publicly available.

There are many ways to get in touch with other OpenWrt enthusiasts and developers.

## Web forum

The [OpenWrt Forum](https://forum.openwrt.org/) is the place for web-based community communication:

- [Release and security announcements](https://forum.openwrt.org/c/announcements)
- [Installing and using OpenWrt](https://forum.openwrt.org/c/general)
- [Hardware questions and recommendations](https://forum.openwrt.org/c/hardware-questions-and-recommendations)
- [For developers](https://forum.openwrt.org/c/devel)
- [Documentation discussion](https://forum.openwrt.org/c/documentation)
- [Community builds, projects & packages](https://forum.openwrt.org/c/community-builds-projects-packages)
- [Feature requests](https://forum.openwrt.org/c/feature-requests/)
- [Site feedback and other questions](https://forum.openwrt.org/c/site-feedback)

## Important changes and announcements

Important changes such as new releases or critical security fixes can be received via several channels:

- [openwrt-announce mailing list](https://lists.openwrt.org/mailman/listinfo/openwrt-announce) — releases and security announcements
- [Security advisories](/advisories/) ([RSS](/advisories/index.xml))
- [Forum announcements category](https://forum.openwrt.org/c/announcements/14) ([RSS](https://forum.openwrt.org/c/announcements/14.rss) / [JSON](https://forum.openwrt.org/c/announcements/14.json))

## Mailing lists

Communication happens on several public mailing lists:

1. [openwrt-devel](https://lists.openwrt.org/mailman/listinfo/openwrt-devel) — patch submissions and general development discussion
2. [openwrt-adm](https://lists.openwrt.org/mailman/listinfo/openwrt-adm) — project administration
3. [openwrt-announce](https://lists.openwrt.org/mailman/listinfo/openwrt-announce) — release and security announcements
4. [openwrt-bugs](https://lists.openwrt.org/mailman/listinfo/openwrt-bugs) — bug tracking notifications
5. [lede-commits](https://lists.infradead.org/mailman/listinfo/lede-commits) — commits to `openwrt/openwrt.git` and `web.git`

## IRC channels

Three IRC channels are hosted on [OFTC](https://www.oftc.net/):

1. [#openwrt](irc://irc.oftc.net:6697/#openwrt) — for everyone
2. [#openwrt-devel](irc://irc.oftc.net:6697/#openwrt-devel) — for developers
3. [#openwrt-adm](irc://irc.oftc.net:6697/#openwrt-adm) — for project organisation

See the [IRC contact page](https://openwrt.org/irc) for further details.

## Corporate inquiries

Direct general inquiries (*not* support requests) to [contact@openwrt.org](mailto:contact@openwrt.org) to open a confidential discussion with the project developers.

The [contact@openwrt.org](mailto:contact@openwrt.org) mailbox is not always well monitored. If you do not get an answer, or the matter is important, use the public mailing list [openwrt-adm@lists.openwrt.org](mailto:openwrt-adm@lists.openwrt.org) instead.

This contact address is primarily intended to find a suitable mode of cooperation and to inquire about project matters without having to disclose your corporate identity upfront.

See the [project rules](/rules/) for further information. Actual development should happen in public, and corporations are strongly encouraged to send contributions through the public mailing lists or as GitHub pull requests.
