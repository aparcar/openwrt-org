The pages you are reading now — the project's landing page, news, and the static "About" / "Rules" / "Trademark" / "License" pages — are generated by [Hugo](https://gohugo.io/) from Markdown files. The bulk of the project's documentation, the [Table of Hardware](https://openwrt.org/toh/start), the [package directory](https://openwrt.org/packages/start), and similar wiki-living material are served from a separate DokuWiki at [openwrt.org/docs](https://openwrt.org/docs/start) and adjacent paths.

## What lives where

- **Static site (this repository).** Project info, governance documents, news posts, contact and contribution guides. Source on git, edited by pull request.
- **Wiki ([openwrt.org/docs](https://openwrt.org/docs/start)).** User and developer documentation, supported-device pages, package descriptions, FAQ, security advisories. Edited in-browser by accredited wiki users.
- **Forum ([forum.openwrt.org](https://forum.openwrt.org/)).** Community discussion, support questions, announcements.
- **Downloads ([downloads.openwrt.org](https://downloads.openwrt.org/)).** Release images, package feeds, sources.

## Reporting issues with this site

For typos, broken links, or content suggestions on the static pages, open a pull request or issue against the website repository. For wiki content, edit the wiki page directly (see [Contributing to the wiki](/contributing-to-wiki/) for how to get an account).

## Branding

Logos, favicons, and the OpenWrt colour palette used on this site come from the [openwrt/branding](https://github.com/openwrt/branding) repository. External use of the marks is governed by the [trademark policy](/trademark/).
