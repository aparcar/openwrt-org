---
title: "OpenWrt 25.12.2 released"
date: 2026-04-22
description: "Point release for the 25.12 series with bug fixes and security updates."
---

OpenWrt 25.12.2 is now available. This is a maintenance release for the 25.12 stable series, bringing kernel updates, security fixes, and a number of device-tree corrections.

Existing 25.12.x users can upgrade in-place with `sysupgrade`. Fresh installs and per-device images are available from [downloads.openwrt.org](https://downloads.openwrt.org/releases/25.12.2/).

The full changelog and list of fixed CVEs is published alongside the release artifacts.
